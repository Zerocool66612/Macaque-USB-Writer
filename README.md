# Macaque USB Writer 🐵

A modern Linux USB image writer inspired by Fedora Media Writer and Popsicle.

## Features

- ISO and IMG image support
- Automatic USB detection
- Modern dark interface
- Writing progress
- SHA-256 verification
- Polkit administrator authentication
- USB safety checks
- Debian/Ubuntu installation support

## Version

0.3 Beta

## Installation

Install the .deb package from the Releases section.

## Development

Built using Python and PySide6.
